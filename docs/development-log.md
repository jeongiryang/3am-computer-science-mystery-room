## 2026-05-17

- 현재 MVP를 약 10분 분량의 2D 미스터리 탐험 게임으로 확장하는 방향을 문서화함.
- 확장 방향은 공과대학 내부 멀티룸 탐험 구조로 정리함.
- 최소 공간으로 55516, 5층 복도, 과사무실, 층 이동 구간, 55110, 공과대학 메인 건물 내부, 서버실 또는 최종 접근 제한 공간을 설정함.
- 아트 디렉션은 차갑고 정적인 새벽 공과대학 분위기, 청회색/네이비/무채색 중심 팔레트, 절제된 UI와 사운드 방향으로 정리함.
- 이번 기록은 설계 문서 작업이며, 실제 scene, script, asset 구현은 진행하지 않음.
