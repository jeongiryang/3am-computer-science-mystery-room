# Game Design Document

## 게임 제목

3AM Computer Science: Mystery Room

## 한국어 제목

새벽 3시, 컴퓨터공학과: 미스터리룸

## 장르

2D 인터랙티브 미스터리 룸

## 예상 플레이타임

첫 완성 버전 기준 약 5분에서 10분

## 핵심 콘셉트

플레이어는 새벽 3시 컴퓨터공학과 실습실 안에서 깨어납니다. 실습실 문은 잠겨 있고, 주변에는 누군가 의도적으로 남긴 듯한 단서들이 흩어져 있습니다.

게임의 핵심은 좁은 공간을 차분히 조사하고, 단서 사이의 연결을 찾아 비밀번호를 추론한 뒤 탈출하는 것입니다.

## 배경

배경은 불이 거의 꺼진 컴퓨터공학과 실습실입니다. 모니터 불빛, 화이트보드의 흔적, 책상 위 메모, 잠긴 문이 주요 분위기를 만듭니다.

장소는 현실적인 학교 실습실을 기반으로 하지만, 새벽 3시라는 시간대와 설명되지 않는 상황을 통해 미스터리와 불안감을 줍니다.

## 플레이어 목표

플레이어의 목표는 실습실 안의 오브젝트를 조사해 단서를 모으고, 최종 비밀번호를 알아내 잠긴 문을 열어 탈출하는 것입니다.

## 주요 오브젝트

- 잠긴 문
- 비밀번호 입력 패널
- 컴퓨터 모니터
- 책상 위 메모
- 화이트보드
- 실습실 책상과 의자
- 의미심장한 개인 물건 또는 흔적

## 주요 퍼즐 구조

1. 플레이어가 실습실 내부를 조사합니다.
2. 메모, 컴퓨터 화면, 화이트보드에서 조각난 단서를 얻습니다.
3. 단서들은 숫자, 시간, 과목명, 코드 조각 같은 컴퓨터공학과 관련 요소로 연결됩니다.
4. 플레이어는 단서의 순서를 정리해 비밀번호를 추론합니다.
5. 비밀번호 입력 패널에 정답을 입력하면 문이 열립니다.

## 엔딩 콘셉트

플레이어는 문을 열고 실습실 밖으로 나가지만, 복도는 완전히 안전해 보이지 않습니다. 짧은 탈출 성공 엔딩으로 마무리하되, 더 큰 사건이 이어질 수 있다는 여운을 남깁니다.

## 미래 1인칭 호러 프로젝트와의 연결

이 프로젝트는 추후 제작할 수 있는 1인칭 호러 탐험 게임의 세계관 입구 역할을 합니다.

현재 게임은 한 개의 실습실에서 진행되는 짧은 2D 미스터리 룸이지만, 이후에는 같은 컴퓨터공학관을 배경으로 복도, 강의실, 서버실, 교수 연구실 등을 탐험하는 1인칭 호러 게임으로 확장할 수 있습니다.

## 첫 플레이어블 버전 목표

첫 플레이어블 버전의 목표는 컴퓨터 실습실 1개 안에서 이동, 조사, 단서 확인, 비밀번호 입력, 엔딩 전환까지 이어지는 최소 게임 루프를 완성하는 것입니다.

이 버전은 전체 세계관을 설명하기보다, 플레이어가 짧은 시간 안에 방을 조사하고 하나의 퍼즐을 풀어 탈출하는 경험에 집중합니다.

## 첫 번째 방 구성

첫 번째 방은 컴퓨터공학과 실습실 하나로 제한합니다. 시점은 2D 탑다운 방식이며, 플레이어는 실습실 안을 자유롭게 이동하며 오브젝트를 조사합니다.

방 안에는 컴퓨터, 칠판, 책상, 사물함, 출입문이 배치됩니다. 각 오브젝트는 퍼즐 단서 또는 탈출 조건과 연결됩니다.

## 플레이어 행동

- 실습실 안에서 2D 탑다운 시점으로 이동합니다.
- 조사 가능한 오브젝트 가까이에서 상호작용합니다.
- 오브젝트 설명과 단서를 확인합니다.
- 단서를 조합해 출입문 비밀번호를 추론합니다.
- 출입문에 비밀번호를 입력합니다.
- 정답을 입력하면 엔딩 화면으로 이동합니다.

## 상호작용 오브젝트 목록

- 컴퓨터: 화면에 남아 있는 메시지나 코드 조각을 통해 비밀번호 단서 일부를 제공합니다.
- 칠판: 수업 흔적, 숫자, 키워드 등을 통해 단서의 순서나 해석 방향을 제공합니다.
- 책상: 메모 또는 개인 물건을 통해 추가 단서를 제공합니다.
- 사물함: 잠긴 공간 또는 이름표를 통해 비밀번호와 연결되는 정보를 제공합니다.
- 출입문: 최종 비밀번호를 입력하는 탈출 오브젝트입니다.

## 첫 번째 퍼즐 흐름

1. 플레이어는 컴퓨터 실습실에서 시작합니다.
2. 컴퓨터, 칠판, 책상, 사물함을 조사해 비밀번호와 관련된 단서를 얻습니다.
3. 각 단서는 독립적으로는 불완전하지만, 함께 보면 하나의 간단한 비밀번호로 이어집니다.
4. 플레이어는 단서의 의미와 순서를 추론합니다.
5. 출입문을 조사하면 비밀번호 입력 UI가 나타납니다.
6. 올바른 비밀번호를 입력하면 출입문이 열리고 엔딩 화면으로 전환됩니다.
7. 틀린 비밀번호를 입력하면 문이 열리지 않고 다시 시도할 수 있습니다.

## 성공 조건

첫 플레이어블 버전은 다음 조건을 만족하면 성공으로 봅니다.

- 플레이어가 컴퓨터 실습실 안에서 이동할 수 있습니다.
- 5개의 조사 오브젝트가 존재합니다.
- 각 오브젝트는 짧은 조사 텍스트 또는 단서를 제공합니다.
- 출입문에서 비밀번호를 입력할 수 있습니다.
- 올바른 비밀번호를 입력하면 엔딩 화면으로 넘어갑니다.
- 플레이 시작부터 엔딩까지 하나의 완성된 흐름으로 진행됩니다.
